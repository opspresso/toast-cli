Simplify your AWS, Kubernetes & Git workflow

A powerful, plugin-based CLI tool designed for DevOps engineers and cloud practitioners.

Get Started View on GitHub 
$ pip install toast-cli
$ toast --help
$ toast am      # Show AWS identity
$ toast cdw     # Navigate workspace directories
$ toast ctx     # Manage Kubernetes contexts
$ toast dot     # Manage .env.local files with S3 env-store
$ toast prompt  # Manage .prompt.md files
$ toast ssm     # Manage SSM parameters
$ toast env     # Manage AWS profiles
$ toast git     # Manage Git repositories
$ toast region  # Set AWS region
$ toast version # Display current version
